# φ⁷ 편대유지 효용항 설계

아웃라인 §IV의 상세 유도. 원논문 수식 번호는 Part II(arXiv 2305.03778) 기준. 아웃라인의 설계 쟁점 ①②③을 각각 §3, §5, §6에서 해소.

---

## 1. 원논문 구조 요약 (설계가 지켜야 할 계약)

- 효용함수: `u_i = Σⱼ ω⁽ʲ⁾ᵢ φ⁽ʲ⁾ᵢ(X)` (식 2.6), φ¹~φ⁶은 식 2.7~2.12. **φ³·φ⁴가 이미 Gaussian 곱 형태** — Gaussian은 원논문 함수족 안에 있음.
- φ⁶ = `ln[1 + 10·exp(−20·dij)]`, dij = **minⱼ** |rij| − 2Rr (로봇 표면 간 최단거리, 로봇당 스칼라 1개). 근접 시 커지는 벌점형(ω⁶ < 0 필요 — 가중치 수치는 미공개).
- Koopman 변수: z⁽¹⁾=X∈R¹² (선형·정확, 식 2.18), z⁽²⁾=효용성분 18개(3로봇×6항, 식 2.20~2.25).
- bilinear 근사 = 동작점 x₀=[z⁽¹⁾₀; z⁽²⁾₀; U₀=0] 둘레 **2차 Taylor 전개**(식 2.45~2.49), UᵀH₃₃U 무시 → **U-affine** → LP 변환 가능. 파라미터화는 φᵢⱼᵀgᵢⱼ 곱(식 2.53~2.59), RLS로 추정.
- **계약**: 새 항 φ⁷은 (a) X만의 함수여야 하고(그래야 φ⁷(AX+BU)에 동일 전개 적용), (b) 로봇당 스칼라로 z⁽²⁾에 추가되며, (c) 동작점에서 z⁽²⁾₀ 계산 가능해야 한다.

## 2. φ⁷ 정의 (제안)

편대 그래프 G=(V,E): 로봇을 노드로, 유지할 거리쌍을 엣지로. 각 엣지 (i,j)∈E에 목표 중심간거리 d*ij (> 2Rr + d_safe).

```
φ⁽⁷⁾ᵢ(X) = Σ_{j: (i,j)∈E} exp( −(|rij| − d*ij)² / σ² ),   rij = (xi−xj, yi−yj)
```

- |rij|는 **중심간거리** (φ⁶의 표면거리와 달리 — 충돌은 φ⁶이 전담, φ⁷은 거리 성형만).
- 로봇당 스칼라 1개(이웃 합) → 원논문의 per-robot 변수 규약(φ⁶의 min 패턴) 유지.
- 합(sum)이지 곱(product)이 아님: 곱은 한 쌍만 어긋나도 전체가 0 → 그래디언트 소실. 합은 각 쌍의 복원력이 독립적으로 살아있음.
- u_i에 ω⁽⁷⁾ᵢ > 0으로 추가: `u_i = Σⱼ₌₁⁷ ω⁽ʲ⁾ᵢ φ⁽ʲ⁾ᵢ(X)`.

## 3. 쟁점 ① — 거리 기반의 대칭성: 강성 그래프로 해소

거리 제약만으로는 편대가 회전·반사·병진까지만 결정된다. 대응:

- **E를 2D 최소 강성(minimally rigid) 그래프로 선택** (|E| = 2N−3): 형상(shape)이 반사 하나를 제외하고 유일하게 결정. N=3 삼각형은 3엣지 = 완전그래프 = 강성 — E2 시나리오는 자동 충족.
- 병진·회전 자유도는 **기존 φ¹·φ³(목표점 추종 항)이 앵커 역할**로 이미 제거 — 각 로봇의 목표점 (xi*,yi*)를 원하는 최종 배치로 주면 절대 자세까지 고정된다. 즉 φ⁷은 "이동 중 형상 유지"를 담당하고 종단 배치는 기존 항이 담당하는 분업.
- 논문 스코프 선언: distance-based (relative) formation + target-anchored placement. 반사 모호성은 초기조건이 목표 형상과 같은 방향(orientation)이면 실질적 문제 아님 — E2에서 확인, §VI에서 한 줄 언급.

**부수 효과 (기여 C3 직결)**: 전체쌍 C(N,2) 대신 강성 그래프 |E|=2N−3 → 편대 항의 결합이 **N에 선형**. 아래 §7 차원 분석의 근거.

## 4. Koopman 변수화·bilinear 전개 (원논문 패턴 그대로)

- 새 Koopman 변수: `z_{30+i}(k) = ψ(X(k)) = φ⁽⁷⁾ᵢ(X(k))`, i=1,2,3 → z⁽²⁾ ∈ R²¹ (3로봇×7항), z ∈ R³³.
- φ⁷은 위치만의 함수 ⇒ φ⁽⁷⁾ᵢ(AX+BU)에 식 2.45 전개가 그대로 적용되고, UᵀH₃₃U 무시 후 **U-affine 구조 보존** — LP 변환(원논문 §4)이 수정 없이 성립. 이것이 "파이프라인 재사용" 주장의 수식적 근거.
- 동작점: z⁽¹⁾₀ = 목표 배치(원논문과 동일), z⁽²⁾₀의 φ⁷ 성분 = 목표 배치에서의 값. 목표 배치가 편대 형상 그 자체이므로 |rij|=d*ij ⇒ **φ⁽⁷⁾ᵢ = deg(i) (최댓값), 그래디언트 = 0, Hessian 음정치** — Taylor 전개가 극대점 둘레라 2차 항이 지배적. bilinear 근사에 가장 유리한 지점에 동작점이 놓인다.

## 5. 쟁점 ② — φ⁶와의 상충: 스케일 분리 조건

φ⁶ 기울기 |dφ⁶/dd| = 200e⁻²⁰ᵈ/(1+10e⁻²⁰ᵈ) (d = 표면거리). **규약**: 원논문 식 2.12는 같은 줄에서 dij = |rij|−2Rr와 min‖·‖−Rr로 자기모순인데, 물리적으로 맞는 **표면거리 |rij|−2Rr**를 채택한다(구현·논문 각주에 명시). 수치 확인(2026-08-03 계산):

| 표면거리 d | \|dφ⁶/dd\| | 비교: φ⁷ 최대기울기 √(2/e)/σ |
|---|---|---|
| 0.1 m | 11.5 | σ=1일 때 0.858 |
| 0.3 m | 0.48 | |
| 0.5 m | 9.1×10⁻³ | ← φ⁷의 ~1% |
| 1.0 m | 4.1×10⁻⁷ | ← 사실상 0 |

**설계 조건**: `d*ij − 2Rr ≥ 0.5 m` (권장 1 m)이면 목표 편대 거리에서 φ⁶ 간섭이 φ⁷ 복원력의 1% 이하 → 두 항의 역할 분리(근거리 척력 vs 목표거리 복원력)가 가중치 튜닝 없이 구조적으로 성립. 논문에는 이 표를 조건식과 함께 제시.

## 6. 쟁점 ③ — σ 선택: bilinear 근사 품질과의 결합

- bilinear 모델은 동작점 둘레 2차 전개(§4) ⇒ Gaussian이 2차 근사로 잘 잡히는 범위는 |‖rij‖−d*ij| ≲ σ. **σ가 편대오차의 "포획 반경"이자 근사 유효 반경**.
- σ 너무 작음 → 고곡률 → 동작점에서 멀면 RLS가 맞춰야 할 잔차 비선형성 급증(원논문 linear 실패와 같은 메커니즘 예상). σ 너무 큼 → 복원력 √(2/e)/σ 약화.
- 초기값 제안: σ = 0.5·min d*ij (E2에서), E4에서 σ ∈ {0.25, 0.5, 1.0}·d* 스윕으로 사후추정오차(원논문 지표, bilinear <3×10⁻⁴)와 편대오차의 트레이드오프 실측.
- `simplified:` 등방 σ 하나로 시작 — 엣지별 σij가 필요해지면(비대칭 편대) 그때 확장.

## 7. 차원 분석 (기여 C3의 뼈대)

일반 N로봇: z⁽¹⁾∈R⁴ᴺ, U∈R²ᴺ, z⁽²⁾∈Rᵐ. per-component bilinear 회귀벡터 ζ의 차원(식 2.68 패턴):

```
a(N, m) = (6N + m + 1) + 24N² + 6Nm + m²
          └ 아핀·1차 블록 [z⁽¹⁾−z⁽¹⁾₀; z⁽²⁾−z⁽²⁾₀; U; 1] ┘ └ gᵢ₁~gᵢ₅ 2차·bilinear 블록 ┘
```

검산: N=3, m=18 → 37+216+324+324 = **901** = 원논문 ζ∈R⁹⁰¹ (식 2.68). (2026-08-03 리뷰에서 아핀 블록 6N+m+1 누락 정정 — 이전 공식은 864로 원논문과 불일치했음.)

| 구성 | m | ζ 차원 a (N=3) | 비고 |
|---|---|---|---|
| 원논문 (6항) | 6N | 901 | 재현 E1 기준값 |
| φ⁷ per-robot 합 (제안) | 7N | 1075 | N=5: 2941, N=7: 5727, N=10: 11631 |
| per-edge 변수 (대안) | 6N+(2N−3) | 1075 | 강성 그래프면 이것도 선형 |
| per-edge 전체쌍 (반면교사) | 6N+C(N,2) | 1075 | N=10이면 m=105 — 조합 폭발 |

RLS의 P는 a×a라 메모리 8a² 바이트: N=3 → 9MB, N=5 → 69MB, N=7 → 262MB, N=10 → **1.08GB** — E3의 실병목은 시간보다 메모리·O(a²) RLS 갱신. 이 표 자체가 C3 주장(강성 그래프로 선형 스케일링, 전체쌍은 조합 폭발)의 근거.

per-robot 합 vs per-edge 실측 비교는 z⁽²⁾ 레이아웃이 달라지는 별도 확장이라 **v1 스코프에서 명시적으로 제외**(deferred) — v1은 per-robot 합만 구현하고, C3는 N 스윕 실측 + 본 차원·메모리 분석으로 성립시킨다.

## 8. Rosenfelder 2024 대응 (설계 층위)

- φ⁷은 |rij|만의 함수 = **SE(2) 불변량 위에 정의** — 병진·회전 대칭을 효용 설계 층에서 보존. "데이터가 기하를 대체 못한다"는 비판에 대해, 본 설계는 기하 구조(불변량)를 데이터 근사 이전의 설계 단계에 명시적으로 넣었다고 논증.
- 단, 동역학이 이중적분기(홀로노믹)라는 전제는 그대로 — 비홀로노믹 구속의 기하(리 군 구조)는 다루지 않음을 §VI에서 명시. Rosenfelder의 실패 사례는 비홀로노믹 lifting이지 효용항 설계가 아니므로 정면충돌은 아니고, 스코프 경계로 처리.

## 9. E2 비교 베이스라인 (분석노트 '대안' 흡수)

paper-analysis.md의 대안(동작점 z⁽¹⁾₀를 편대 배치로 재정의)은 **φ⁷ 없이 목표점만 편대로 찍는 것** = "individual target assignment" 베이스라인으로 E2에 편입. 예상 차이: 베이스라인은 이동 중 형상 붕괴(각자 목표만 추종), φ⁷은 이동 중에도 형상 유지. 편대오차 시계열 Σ_{(i,j)∈E}(|rij|−d*ij)²로 정량 비교 — 이 차이가 φ⁷의 존재 이유 증명.
